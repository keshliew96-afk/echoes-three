## 1. 一句话

- **D1.** 同区相加，异区相乘。（减伤区和效果抵抗例外：每个来源各自相乘，见 D20、D35。）
- **D2.** 什么都没装的时候，每个区都等于 1，所以今天游戏里的数字不变。

## 2. 伤害类型

| | 类型 | 例子 | 暴击 | 吃增伤 | 吃易伤 | 被减伤、抗性、防御挡 | 算一次命中 |
|---|---|---|---|---|---|---|---|
| D3 | 常规直伤 Direct | 普攻、技能 | ✓ | ✓ | ✓ | ✓ | ✓ |
| D4 | 持续伤害 DoT | 荆棘、大雨（Mosslight） | ✗ | ✓（上 DoT 时锁定） | ✓ | ✓ | ✗ |
| D5 | 附加伤害 Bonus | 被动追加的小伤害 | ✓ | ✓ | ✓ | ✓ | ✗ |
| D6 | 真实伤害 True | 反甲、铁储爆发 | ✗ | ✗ | ✗ | 无视 | ✗ |
| D7 | 生命消耗 HP cost（不是伤害） | Blood Price 烧血 | 不走公式，不经过护盾，永远不会让自己倒地 | | | | |

- **D8. "算一次命中"** = 会触发击中特效：印记、叠层、吵醒睡着的怪、反伤、顿帧、击退。
  不算命中的伤害永远不会触发另一个附加或真实伤害，所以不会无限循环。
- **D9. 真实伤害无视数值，不无视机制。** 护盾照样吸收，冲刺的无敌帧照样躲开，Boss 的无敌阶段照样挡住。
- **D10.** D7 是我加的名字：Stonehide 的烧血已经写成"不是伤害"。

## 3. 伤害公式

- **D11.** 常规直伤 = 基础伤害区 × 暴击区 × 增伤区 × 易伤区 × 减伤区 × 抗性区 × 防御区 × 破绽区
- **D12.** 持续伤害 = 基础伤害区 × 增伤区 × 易伤区 × 减伤区 × 抗性区 × 防御区 × 破绽区
- **D13.** 附加伤害 = 和常规直伤同一条公式，可以暴击，只是不算命中（选项 3a）
- **D14.** 真实伤害 = 基准数值来源 × 真实伤害倍率
- **D15. 结算顺序：** 无敌帧或格挡（没有伤害）→ 公式 → 单击封顶 → 护盾 → 扣血 → 不倒机制。

## 4. 每个区

| | 区 | 怎么算 | 里面放什么 | 上限 |
|---|---|---|---|---|
| D16 | 基础伤害区 | （技能威力 + 属性加成）× 技能自身倍率 | 卡面上的数字；"+X% 最大生命"；写在这个技能或连招上的条件（Crescent Finisher +50%，Spike +50%） | 无 |
| D17 | 暴击区 | 暴击时 1 + 暴击伤害，否则 1 | 暴击率 5% 起，暴击伤害 50% 起，各自相加 | 暴击率 100% |
| D18 | 增伤区 | 1 + 全部增伤之和（4a） | 天赋、印记、遗物、队友给的"造成伤害 +X%" | 无 |
| D19 | 易伤区 | 1 + 目标身上易伤之和 | exposed、标记；同名取最大，不同名相加 | +100% |
| D20 | 减伤区 | 每个减伤各自相乘：（1 − 甲）×（1 − 乙）× …（5b） | ward、Stone、Bark；攻击者被削弱（虚弱）也算一个 | 无。相乘永远到不了 100% |
| D21 | 抗性区 | 1 − 抗性（弱点是负的抗性）（1a） | 按伤害形态：近战、远程、范围、持续。只有精英、冠军、Boss 才有，小怪没有 | 抗性和弱点各 50%，没有免疫 |
| D22 | 防御区 | 100 ÷（100 + 防御 ×（1 − 减防 − 无视防御））（2a） | 小怪 0，精英 25，冠军 40，Boss 50，英雄 0；有防御的怪血量只稍微调低（D39） | 防御最低 0 |
| D25 | 破绽区 | Boss 被撞晕或力竭时 1.25 到 1.3，否则 1（6a） | 游戏里已有的 Boss 窗口 | 无 |

- **D23. 真实伤害的"基准数值来源"只有四种：**
  1. 触发它的那一击的最终伤害。队友的增伤、易伤已经算在里面了，这就是"间接吃满辅助收益"。
  2. 自己承受的那一击（减伤之前）。Stonehide 的反甲。
  3. 生命值：最大生命的 X%，或烧掉的血。
  4. 储存量。Stonehide 的铁储。
- **D39. 有防御的怪，血量只稍微调低**（Kesh，11:52："no need to reduce too much HP, slightly reduce will do"）：精英 −5%，冠军 −8%，Boss −10%。
  所以没有减防的打法打它们会慢一些（精英约慢 19%，冠军约 29%，Boss 约 35%）；减防、无视防御、真实伤害把这段时间打回来。
- **D26. DoT 的锁定（7a）。** 上 DoT 的那一刻记下我方的增伤；敌人身上的易伤、减伤、减防每一跳实时算。重新上一次就重新锁定。

**D24. 例子。** Ashfang 的 Crescent Finisher 打 Boss：基础 20 × 1.5 = 30；暴击 × 1.5；增伤 8% + 10% = × 1.18；
易伤 20% + 20% = × 1.4；Boss 防御 50 = × 0.667。结果约 **50**；Boss 被撞晕时 × 1.25 = **62**；小怪没有防御，同一刀是 **74**。

## 5. 治疗公式（8a）

- **D27.** 治疗 = 基础治疗区 × 暴击区 × 治疗加成区 × 受疗区
- **D28.** 治疗加成区在施法者身上，受疗区在目标身上（Rings、sweetened），各自相加。减疗（诅咒）是另一个乘数。
- **D29.** 持续治疗（Moss）不暴击，和 DoT 对称；治疗加成在上的那一刻锁定。Sap 的灌注不暴击（已通过）。

## 6. 护盾公式（新）

- **D30.** 护盾量 = 基础护盾区 × 暴击区 × 护盾加成区 × 受盾区
  - 基础护盾区 =（技能数值 + 属性加成，比如最大生命的 X%）× 技能自身倍率
  - 护盾可以暴击（10b），用施法者的暴击率和暴击伤害，和治疗一样。
  - 护盾加成区在施法者身上，受盾区在目标身上，各自相加。
- **D31. 护盾挡的是公式算完之后的伤害。** 所以减伤和防御让护盾更耐打，易伤让护盾掉得更快。
- **D32. 护盾挡什么：** 直伤、DoT、附加、真实伤害都挡。不挡生命消耗（烧血）。
- **D33. 叠加（9a，Kesh："total 盾量无上限 but in detail will have each shield amount and its timer, so once timer reach the shield disappear"）：**
  - 每层护盾是自己的一条：自己的量，自己的计时。计时到了，那一层就消失。
  - 不同来源的护盾相加，总量没有上限（今天"最多最大生命 50%"的上限取消）。
  - 受伤时先扣最快到期的那一层。
  - 同一个技能重新给同一个人：换成较大的量并刷新计时，不多开一层。
  - 血条上显示总量；细看时列出每一层的量和剩余时间。
- **D34.** 打在护盾上仍算一次命中，也算攻击者造成的伤害（Sap、统计）。护盾被打破时发一个事件，可以挂效果（今天的 Detonate 就是这样）。

## 7. 效果抵抗（新，韧性 Tenacity）

- **D35.** 控制时间 = 基础时间 × 延长区 ×（1 − 效果抵抗）
  - 延长区在施控者身上，相加（Mosslight 的 Long Season +30%、Linger 节点）。
  - 效果抵抗在被控者身上，多个来源各自相乘，和减伤区一样。
- **D36. 缩短哪些：** 眩晕、定身、睡眠、嘲讽、致盲、减速（包括 soaked）的**时间**。
  - 不缩短位移：挑飞、击退、拉拽、抛起（和 LoL 的击飞一样）。
  - 不缩短伤害类减益：易伤、减防、DoT、标记。
  - 只管时间，不管幅度：40% 的减速还是 40%。
- **D37. 谁有：** 小怪 0，精英 20%，冠军 30%，**Boss 80%**（11b），英雄 0（遗物、天赋以后可以给）。最短 0.25 秒，保证看得见。
- **D38. 已有的上限不变：** 眩晕最长 1 秒、之后 2 秒免疫；这些上限在公式之后再卡一次。
- **D40. Boss（11b）：不再免疫，改成 80% 效果抵抗。** 1 秒的眩晕在 Boss 身上是 0.25 秒，3 秒的减速是 0.6 秒。和它一起的三条保护（我的猜测）：
  1. Boss 仍然不能被推、拉、挑飞。位移不归效果抵抗管。
  2. Boss 已经亮出预警的招式不会被控制打断，只是它的下一个动作被推迟。玩家读到的预警永远是真的。
  3. Boss 吃完一次硬控（眩晕、定身、睡眠、致盲）之后 5 秒内不吃硬控，和今天 Boss 的嘲讽规则一样。减速没有这个间隔。
- **D41.** Boss 的嘲讽规则照旧（最多 1 秒，之后 5 秒免疫）。
