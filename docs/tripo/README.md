# Tripo review standards

The rules each kind of Tripo model was rigged, animated and reviewed against, copied from the project
folder on 2026-11-15 (BUILD_BRIEF A23). These copies are the ones to change from now on; the system
doc is `docs/TRIPO_MODELS.md`. Paths inside them that start `/mnt/project-files/` (or `tripo-...`)
point at the project folder, where the GLBs, kits and review pages stay.

| File | Kind | Adds to |
|---|---|---|
| `CHARACTER_REVIEW_STANDARD.md` | heroes (and the base for every kind) | none |
| `BOSS_REVIEW_STANDARD.md` | bosses | the hero standard |
| `CHAMPION_REVIEW_STANDARD.md` | champions | the boss and hero standards |
| `MOB_REVIEW_STANDARD.md` | foes and small mobs | the hero and boss standards |
| `NPC_REVIEW_STANDARD.md` | camp and event NPCs | the mob standard |
