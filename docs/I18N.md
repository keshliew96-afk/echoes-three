# Languages (i18n)

Echoes ships its player-facing text in ten languages:

| Code | Language | Name shown in the menu |
|---|---|---|
| `en` | English (source) | English |
| `zh-Hans` | Simplified Chinese | 简体中文 |
| `zh-Hant` | Traditional Chinese | 繁體中文 |
| `ja` | Japanese | 日本語 |
| `ko` | Korean | 한국어 |
| `es` | Spanish | Español |
| `pt-BR` | Brazilian Portuguese | Português (Brasil) |
| `fr` | French | Français |
| `de` | German | Deutsch |
| `ru` | Russian | Русский |

`docs/BUILD_BRIEF.md` names no list, so these are the ten most-played web game
languages with Chinese split into its two scripts.

## Player view

- **Settings ▸ Gameplay ▸ Language** picks the language. Each language is listed
  in its own script; **Apply language** stores `ui.language` and reloads the
  page, so every screen is rebuilt in it. In a run the game asks first, and the run
  continues from its last autosave (the start of the current room) through
  Continue.
- With no stored choice the game follows the browser's language when it is one
  of the ten (`zh-TW` / `zh-HK` / `zh-Hant` -> Traditional, other `zh` ->
  Simplified, any `pt` -> Brazilian Portuguese), else English.
- `?lang=<code>` forces a language for one page load without storing it
  (probes and screenshots).
- Co-op: the language is a local setting. Each player sees their own language;
  nothing about it crosses the wire. Text the host sends (room names, player
  names) is shown as sent.

## How the text is looked up

`src/i18n/index.js`:

```js
import { t, tn } from '../i18n/index.js';
t('Choose your class');                       // a fixed line
t('Health {hp}', { hp: st.maxHp });            // placeholders, filled after lookup
tn(count, '{n} Ember', '{n} Embers');          // plurals via Intl.PluralRules
t(relic.name);                                 // data names: the English name is the key
```

- The English text is the key (`t('Mouse@@input device')` adds a context after `@@` when one English word needs two translations; English shows the part before `@@`). A line with no translation shows in English, so a
  missing line never shows a raw key. In a non-English language every miss is
  recorded in `window.__echoes.i18n().misses` for the probe.
- Tables live in `src/i18n/locales/<code>.json`: `{ "English line": "translation" }`.
  A plural line is keyed by its English `other` form and maps to
  `{ "one": ..., "few": ..., "many": ..., "other": ... }` (the forms
  `Intl.PluralRules` gives that language). Only the active table is loaded.
- `tools/i18n-extract.mjs` collects every key (literal `t(...)` / `tn(...)`
  calls in `src/`, plus the data names and descriptions the UI shows through
  `t(value)`) into `src/i18n/catalog.json`, and `--check` lists, per language,
  keys with no translation and translations whose `{placeholders}` differ from
  the English. `--check` writes nothing (v0.5.318): it fails when the committed
  catalog is out of date, and a plain run refreshes it.
- **No unused entries (v0.5.326).** `--check` also fails on a table entry no
  key asks for, and names it (`unused: ...`). When a line leaves the game,
  delete its entry from all nine tables in the same PR. A line the UI shows
  through a lookup table (`t(TABLE[key])`) counts as asked for only when the
  extractor harvests that table: add the table's name to `NAME_TABLES` in
  `tools/i18n-extract.mjs` (v0.5.326 added `CLASS_CRITTER`, whose Beetle,
  Otter and Bat the check had wrongly called unused). That prune removed 29
  old lines (retired Endless, vow and Boss Rush texts, old door and lead-on
  prompts, the four-hero class pick line, two story pages and the Level III
  and IV wordings of The Long Road and Ringwalker, whose unreachable code
  branches went with them); `tools/prune-strings-probe.mjs`
  lists them and plants an unused entry to prove the check fails.

## Rules for code

1. **Wrap at the display site.** Every string a player can read (text, button
   labels, `aria-label`, `title`, `placeholder`, toasts, notes, help text) goes
   through `t()` where it is put on screen, not where the data is defined.
2. **The sim never translates.** Nothing under `src/sim/` or `src/core/` imports
   `src/i18n/`. Names and descriptions defined there stay English and are
   translated by the UI with `t(value)`. The nine golden simtrace hashes do not
   depend on the language.
3. **Whole sentences, named placeholders.** Never build a sentence from
   translated fragments (`t('You play the') + name`); write
   `t('You play the {cls}', { cls: t(CLASS_NAME[cls]) })` so a translator can
   move the name. Placeholder names are words (`{hp}`, `{name}`), not `{0}`.
4. **Markup stays out of keys** where possible. When a sentence needs inline
   emphasis, the key may hold simple `<b>…</b>` tags; translations keep them.
   Escape *after* translating (`esc(t(x))`).
5. **Not translated:** key-cap labels (`Esc`, `Enter`, `Shift`, `Space`, letter
   keys), room codes, player-typed names, version numbers, debug / probe
   output, `?vfxlab=1` and `?debug=1` panels, console messages.
6. **Case.** Upper-casing happens after lookup (`t(x).toUpperCase()`), which is
   a no-op for scripts without case.
7. **Never compare displayed text** in logic; compare ids or data values.

## Fonts

The UI font stacks (`AP_FONT`, the HUD's `FONT_STACK` and the system-ui stacks
in the run and socket screens) end with `var(--i18n-font, sans-serif)` (`AP_FONT`
and `FONT_STACK` since v0.5.324; before, they ended in plain `sans-serif`). Boot
sets `<html lang>` and, for Chinese, Japanese and Korean, `--i18n-font` to that
script's system fonts (PingFang / Microsoft YaHei / JhengHei, Hiragino /
Yu Gothic / Meiryo, Apple SD Gothic Neo / Malgun Gothic, then Noto CJK) so each
language gets its own glyph shapes. Latin and Cyrillic are covered by the
existing system stacks. No web font is downloaded.

## Proper nouns

Class, boss, enemy, relic, curse, skill and land names are translated where the
language has a natural rendering (the Healer, the Hollow Stag, the Sunken Mill)
and kept consistent across every screen in that language. Coined words with no
rendering are transliterated (CJK, Russian) or kept (Latin-script languages).
"Echoes" the game title stays as is in every language.

## House conventions

- Distances read **u** in every language (never m, ед., 单位 or a translated word).
- A long one-word name (German, Russian, Spanish, French) gets a soft-hyphen entry in
  `NAME_BREAKS` (`src/ui/run/classpick.js`); names on the picker shrink at most 20%, so
  readable beats small.
- New relic, deed, power and skill text states its numbers the same way the existing rows
  of that kind do, and keeps the same names for the same things across every screen.
- Check new text in German or Russian at 1024x640 before calling it done.
- Dates read in the game's language: `toLocaleDateString(getLanguage(), …)`, falling
  back to the browser's only if the game's is refused (the Records high scores and the
  kept-aside file, the Daily's day, cloud saves). The Saves screen's slot times still
  read the browser's language.
- The Level Select keeps its cards in one row while they fit. When they do not (all nine
  cards at 1024x640 in every language but Chinese, or at 1280x720), `fitRows()` in `src/ui/run/levels.js`
  stands them in two rows (five over four), moves each card's blurb into the line under
  the rows for the focused card, and lets ← → walk the cards in order across both rows
  (↑ ↓ move between rows). It measures the window, so a short window, a long language
  or the vow band all take two rows the same way. The Danger pips and Boss Rush rings
  wrap under their label on a narrow card instead of running past its edge.
  `tools/polish-browser.mjs --only levels` checks all ten languages at 1024x640.

## Left in English on purpose

- Key caps and gamepad buttons (Esc, Enter, F1–F4, LB/RB, D-pad, Start), room
  codes, version numbers, command lines (`npm run serve`) and the README
  section name the network help points at.
- Two rare messages with a number built in outside the UI: the co-op
  "That room runs a newer/older version of Echoes (vX)" line from
  `src/net/lobbyClient.js`, and the repaired-save summary from
  `src/save/content.js describeRepair()`.
- The `?vfxlab=1` and `?debug=1` panels.

## Checks

- `node tools/i18n-extract.mjs --check`: every language has every key, with the
  same `{placeholders}` and tags, no entry nothing asks for, and the catalog is
  up to date. `npm test` runs it and `tools/prune-strings-probe.mjs`.
- `node tools/i18n-browser.mjs` (dev server on 5199): 21 screens per language
  at 1024x576 (title, five settings tabs, saves, records, online play, camp,
  class select, unlocks, level select, combat HUD, draft, socket, relic pick,
  doors, pause, peddler, run end). Fails on a line with no translation, visible
  text still in English, text clipped or off the window where English fits,
  or a page error. `--shots <dir>` saves a screenshot of each.
