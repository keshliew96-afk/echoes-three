|---|---|---|
| B1 | Separate buses (Master, Music, SFX at least; often Ambience/UI/Voice) each with its own fader; every bus routes to one master. | FMOD Studio mixer groups in Hades/Dead Cells: Master > Music / SFX / VO / Ambience. |
| B2 | Buses are decoupled: moving Music never changes SFX level and vice versa; Master scales everything equally. | FMOD VCA/bus independence. |
| B3 | Volume slider feels perceptually even: 50% sounds about half as loud (about -10 dB), not barely quieter (-6 dB linear). The endpoint 0 is true silence. | Wwise/FMOD VCA in dB; Unity AudioMixer faders with log mapping (20*log10 / curve); Hades volume sliders. |

| B5 | Master limiter/ceiling: a heavy fight (boss + adds + many hits) never clips above 0 dBFS; limiter does not pump audibly (short gain reduction). | FMOD master-bus compressor/limiter in Hades; Wwise Peak Limiter on master. |
| B6 | Voice management: per-event max instances + stealing + cooldown so 6 simultaneous hits do not stack 6x louder; total voice cap. | FMOD event "max instances / steal oldest", Wwise playback limit. |
| B7 | Music by game state: menu, hub, combat, boss, victory/defeat stingers, each distinct; transitions crossfade (roughly 1-3 s), no hard cuts, no dead air > 1 s between states. | Hades: music layers/stems swap by state; Dead Cells biome themes crossfade. |
| B8 | Music reacts to intensity (layers add with combat intensity) and per-biome/level theme changes at level transitions without stopping. | Hades stem layering; Dead Cells per-biome themes. |

| B10 | Spatial one-shots: a sound on the right of the screen is louder in the right ear (pan), far sounds quieter (attenuation); music/UI non-spatial. | FMOD 3D events with a listener on the camera. |
| B11 | Mix balance: combat SFX peaks sit clearly above music (several dB) so gameplay feedback reads; overall loudness in a sane game range (roughly -24..-14 dBFS RMS short-term; -16..-23 LUFS family). UI clicks audible over music. | Hades/Dead Cells mixes; loudness norms. |
| B12 | Settings persist across restart (levels, mutes, modes); bad/missing values fall back to defaults. | All shipped PC games. |

| B15 | HTML5 autoplay: no AudioContext is created before a user gesture (no Chrome "AudioContext was not allowed to start" warning); first click/key unlocks; a visible "click/press to start" prompt while locked; no page error. | Chrome autoplay policy; Howler/Phaser unlock pattern; itch.io WebGL games. |
| B16 | Pause behaviour: pausing the game ducks/pauses gameplay SFX (and often lowfilters music); unpausing restores. | Hades pause menu lowpass/duck; Dead Cells pause duck. |
| B17 | No voice leak: after a fight ends, active voices drop to near zero; memory/CPU steady over a long run. | Engine profilers. |
| B18 | Zipper-free gain changes (ramped), no clicks when a slider moves or a sound starts/stops. | Wwise/FMOD interpolated parameter changes. |
