## 1. Blind benchmark checklist (written BEFORE inspecting any Echoes capture)

Derived from how the shipped reference games behave. Each item is concrete and testable against Echoes.

### Hades (biome identity, escalating encounters, boon/slot build variety)
- H1. Each biome (Tartarus / Asphodel / Elysium / Styx) has an instantly distinguishable dominant palette (green-teal stone vs. red-orange lava vs. gold-green fields vs. dark red-purple) — a single screenshot identifies the biome. Test: dominant-hue / palette metrics differ materially per level; floor + prop set differ.
- H2. Each biome has its own prop set / architecture and its own music theme. Test: prop/dressing counts differ per level; audio theme id differs per level.
- H3. Encounters escalate inside a biome (early chambers 1 wave, later chambers 2-3 waves, elites/armoured variants later), and a later biome's first chamber is harder than the previous biome's first chamber. Test: per-room enemy count / total HP / waves rise monotonically, biome-start of level N+1 >= biome-start of level N.
- H4. Mini-boss / boss chambers are explicit difficulty spikes, followed by a respite (fountain / shop). Test: boss room budget > any combat room; shop room has no enemies.
- H5. Boons occupy fixed ability slots (Attack/Special/Cast/Dash/Call) — you can never hold two boons in one slot; a new boon for an occupied slot is offered as a REPLACEMENT ("this will replace X"), with the outgoing boon shown, and you can decline by choosing another option. Test: 4-skill cap holds; full-slot reward shows a replace/decline choice with the outgoing skill named.
- H6. Duo/legendary boons have explicit prerequisites and are visually tiered by rarity color (common white / rare blue / epic purple / heroic red / legendary orange). Test: rarity legible on node cards; legendary works on every valid skill.
- H7. The run's build is persistent across biome transitions (boons carry, HP carries unless restored by fountain), with a short transition (elevator/boat) that doubles as loading. Test: build carried L1->L2->L3; transition card ~3 s and skippable.
- H8. Boon reward UI clearly identifies which god/slot a boon applies to and what it replaces; keyboard/mouse/gamepad all navigate. Test: owner/character label + input parity.

### Dead Cells (biome variety, hazard design)
- D1. Each biome has unique hazards (spikes, traps, poison water, explosive barrels) with a readable wind-up; hazards damage enemies too where it makes sense. Test: per-level hazard types exist and differ, have a telegraph, and affect enemies/players as documented.
- D2. Biome-specific enemy rosters: new enemy types appear in later biomes and older ones become variants. Test: roster per level differs; each new enemy has distinct behaviour.
- D3. Interactable environment (doors, breakable walls, levers, chests) always gives visible + audible feedback on interaction, and the interaction prompt is shown in range. Test: every interactable fires a prompt, a state change, and feedback (VFX/SFX/text).
- D4. Scaling across biomes (Boss Cell / tier) raises enemy HP and damage multiplicatively with visible tier. Test: HP/damage multipliers per level increase.

### Enter the Gungeon (enemy readability and telegraphs)
- G1. Each enemy has a unique silhouette readable at small scale (Bullet Kin vs. Shotgun Kin vs. Gun Nut) — you can identify type without color. Test: silhouette distinct at 50% zoom.
- G2. Every attack has a wind-up (flash / pose / sound) before firing; heavy attacks have longer telegraphs (~0.5-1 s). Test: telegraph >= 0.7 s in Ember (spec), visible ground/actor tell.
- G3. Projectiles contrast strongly with the floor (magenta/orange bullets on muted floors). Test: projectile/telegraph contrast vs. biome floor.
- G4. Enemy variety grows per floor with new mechanics (blobs split, wizards teleport, mortar lobbers). Test: each new enemy's behaviour differs (movement pattern, attack geometry).

### Slay the Spire (difficulty curve across acts)
- S1. Act 1 -> Act 2 -> Act 3 enemy HP / damage step up noticeably; elites and bosses are spikes above the act's normal fights. Test: per-act HP/damage/count numbers rise; boss spikes.
- S2. The curve is tuned for an accumulated deck — later acts assume the player's build grew (card rewards each fight, relics). Test: carried build lands each level inside its playability band.
- S3. Rest sites / shops give respite between spikes. Test: shop room + level-transition full heal.
- S4. Card reward choice: 3 options plus Skip; skipping is always allowed. Test: skill reward decline path exists; node rewards skippable.
- S5. Rewards scale with act (more gold, rarer cards later). Test: node rarity/supply over the run fills a meaningful share of the 32 sockets.

### General production UX (applies across all four)
- U1. No crashes / uncaught page errors during any probe.
- U2. UI panels fit at small (1024x576) and large (2560x1440) resolutions without overlap or clipping.
- U3. Every menu fully navigable by keyboard, mouse and gamepad.
- U4. Saves from older versions load (migrated) without crash or data loss.
