### Advisories

- **A1 Host-stall recovery.** After a host main-thread stall of H ms, the guests' inputs run up to ~H ms late and drain ~1:1 (a 2 s stall gives a 1808 ms peak and takes 3.5 s to recover). PLAN says a late frame is applied "<= 250 ms late" (step 20; r3 A1 persists).
- **A2 Rejoin offered for a dead server.** After a server kill the title shows "Rejoin XXXXX? … seat is held" although the server is gone. Rejoin fails cleanly in 2.07 s (step 12; r3 A2 persists).
- **A3 Silent title for a barred host.** The old host barred by admin kill-host lands on a plain title with no message (step 11 E; r3 A3 persists).
- **A4 Dropped lobby member blocks Start.** A lobby member whose socket dies blocks Start for ~10 s, and the message says "Every player must be ready first." instead of naming the dropped player (step 18; r3 A4 persists).
- **A5 Hidden host mid-game.** 3 of 10 two-second windows fall outside 60 ± 2 ticks/s (mean 58.8) (step 19).
- **A6 G5b.9 cannot be shown on this machine.** Hosting 3 bot sims gives 53.3 fps against 60 in single-player, and frameOver50Net 1 on a 2054 ms frame (step 21).
- **A7 G5b.12 literal 17 ms p95.** Not met on this loaded machine: 27-55 ms at 23-30 fps, which is 1-2 frames. With 2 browsers it is 10-20 ms (step 30).
- **A8 Snaps on an overloaded host.** A host at 15 fps (Level 3, 4 browsers) gave guests 2-10 own-body snaps per minute at N1, with no stall, dash or transition in the prior 1.5 s. This did not reproduce with the host at 25 fps (steps 7-8).
- **A9 Old host's solo simulation is discarded.** The old host keeps simulating alone for 15 s ("The game keeps running here") while the guests are frozen and then migrate; everything it did in that time is thrown away (step 11 G).
- **A10 E targets a used Dewfont.** Pressing E next to a fresh Dewfont targets an older used font beside it, so both players get a "used" denial (step 13).
- **A11 Forced-mismatch recovery not exercised.** The debug surface did not let me create a real hash mismatch, so detect-and-heal was not verified (step 28).

Environment: machine-wide freezes of 2.7-3.9 s hit every browser at once in the N1 soak (the single-player control page froze for 2945 ms). I do not attribute these to the game.
