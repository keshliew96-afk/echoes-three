## Decisions (where the PLAN was silent)
- D1 The literal cap: no character ever holds more than 4 skills (no reserve / satchel). An ally starts full, so its skill reward is a SWAP offer (replace one of 4 or Leave); the replaced skill returns to the class pool, its nodes to the bench. Chosen over Darkest Dungeon's 7-known / 4-equipped because the binding correction says a 5th skill is never offered once 4 are owned.
- D2 Per-character purses (the Healer's purse = the §14 wallet, unchanged) instead of one shared wallet: keeps every Healer number, keeps the §14 invariants per shelf, and removes coin contention in co-op.
- D3 One party page with the own card first and AI-held cards pre-decided (Suggested, default) keeps the Healer-only flow at one input per room; Manual / Automatic exist as honest, measurable settings.
- D4 Ally draws use a separate party stream seeded from the gameplay SEED (no gameplay draw): the Healer's draw order and every crit roll stay on the gameplay stream; empty-build ally casts must reproduce v0.5.150's ?room= goldens.
- D5 Allies get 1 clear spoils (Healer 2): four builds grow across the whole campaign (ally full during Level 3) instead of all four maxing in Level 2.
- D6 Class nodes are all techniques (stats stay shared) so every class node reinterprets per skill like the Healer's techniques; each is live on ≥ 3 class skills.
- D7 Deadlines only with ≥ 2 humans, in sim ticks (replicated, saved, pause-consistent); single-player never times the player out.
- D8 Difficulty band is partly baseline-relative (v0.5.150 measured before PARTY's first sim edit) because absolute bars for a four-build party would be guesses.
- D9 PARTYD used preview port 4404 (recorded in PLAN §6.3) because the shared dev server on 5199 was down; not restarted by me.
