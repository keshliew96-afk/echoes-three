## Decisions (PLAN silent)
- D1 The disproof is STATE-based and exact: the seat timers block gains `fire` (last fired basic's input seq); skills / dodge timers are fire-only already. A prediction is confirmed by a host fire inside its ±3 window (`stateConfirmed`, the event still suppresses the replay) or retracted at the first snapshot that covers the window — never on the reliable stream's RTO. Ambiguous case (first covering snapshot already >= one interval past the window) and interacts still use the event stream; a state-confirmed prediction has a 2 s grace before the event stream may retract it (safety valve).
- D2 The held basic is predicted with the host's own rule over a local frame log (basic held, dashing after the step, dash ended on it, alive, stunned, channelling, fresh); the timer is rebuilt from the host's timer at k through every logged frame > k on every snapshot; one basic prediction per ±3 window (`openNear`); the pre-step sample keeps the same-frame feedback of a fresh press, `frame()` after the step evaluates every input frame and re-runs a frame whose sent flags differ (local retraction). Retractions never move the basic timer back; skill / dodge timers return to the host's value or a newer open prediction's.
- D3 A Downed body at k (hp <= 0) retracts every open non-interact prediction on that snapshot (a revive takes seconds), so the gate's forced-mispredict scenario retracts before its window is even consumed.
