## Decisions (PLAN silent — best-in-class choice recorded)
- D1 Relay envelope: every binary frame starts `u8 channel · u8 seat` (host->server: destination seat, 0xFF = all guests; guest->server: overwritten by the server with the sender's seat). PLAN's SNAP header layout follows the envelope.
- D2 HOT quantisation is generic over entity fields (no per-kind schema, so new M4b kinds need no protocol edit): x/z int16 @1/256, hp @0.01, facing / faceX+faceZ -> uint8 yaw (dequantised through a 1/4096-rounded unit-circle table so every JS engine rebuilds identical bytes), aim int16 @1/64, 16 well-known booleans as flag bits; everything else exact in a per-entity rest diff.
- D3 Linear movers (numeric vx, vz, traveled, range) are dead-reckoned: anchor {t0,x0,z0,tr0} sent once, both sides extrapolate with exact IEEE ops; host re-anchors when drift > 1/64 u. Satisfies "replicate spawn parameters once + despawn" while keeping decode exact.
- D4 Not replicated (DROP_KEYS): px/pz (render interpolation history, the replica writes them) and allies `leashD0` (per-tick scratch rewritten before every read). Changes the replicated VIEW only; keyframes (migration) stay exact full trees.
- D5 Tree-diff patches keep PLAN's JSON op semantics (s/d/o/a/k, law verified on both forms) but travel in a binary canonical-value codec (src/net/protocol/bvalue.js, static key/string dictionaries measured from the sim): cut per-guest downstream from ~13-17 KB/s (JSON) to 3.6-6.6 KB/s at 20% loss, under the 12 KB/s budget.
- D6 The quantised-tree hash rides in snapshots whose tick is >= 30 ticks after the previous hashed one (robust to ?netrate=), computed once per snapshot on the host and shared by every guest.
- D7 Conditioner loss/dup/reorder apply to the unreliable class only; reliable-class "loss" = retransmit delay max(200 ms, 2xRTT) per lost attempt, delivery kept in order (head-of-line); outage/blackhole: unreliable dropped, reliable held until the link returns (+1 RTO); bandwidth = GCRA token bucket (50 ms burst), unreliable tail-dropped past 300 ms queue. Compact spec: loss/dup/reo are percent, CLI flags accept fractions.
