## Decisions (PLAN silent -> what a shipped game does)
- D1 Full slots become UPGRADES (Hades turns a full kit into upgrades rather than an empty reward): a node that OUTRANKS a socketed node — dead weight (grey / +0) first, then a lower rarity — is offered, sold and dropped, and auto-fill swaps it in. Rarity is the value ladder because it is the one the game already prices by (15/20/25) and shows everywhere; no new stat is invented.
- D2 LAYERED pools, not a union: the fill layer keeps its exact draws (goldens bit-identical, L1 and the tuned starter grants unchanged); the upgrade layer serves only draws the fill layer cannot. A player who still has vacant sockets sees exactly the old game.
- D3 Spoils stay commons + rares (BUILD_BRIEF §14 keeps legendaries as the draft/shop chase items). A drop is short only when fewer than 2 commons / rares outrank anything; the page says so honestly instead of topping up with a sidegrade that would change nothing. The Level-3 carried build reaches 6-8 legendaries / 21-23 rares by its Stag — the build's ceiling — which is the natural end of a campaign arc; the "BUILD COMPLETE" page only appears when no node can fill or outrank any socket.
- D4 The swap target is part of the offer (card line + in-hand cursor), read live in run.view(), so re-socketing while a page is open never leaves a stale claim. View / event keys exist only when set, so state hashes of fill-only runs are unchanged.
- D5 Auto-fill (one policy for the F key, pad Y, the socket screen button and the autopilot) now performs upgrade swaps; the socket screen tags any manual swap ⇧ upgrade / ⇄ sidegrade / ⇩ downgrade so a deliberate choice is never silently overridden without the player seeing its value.
