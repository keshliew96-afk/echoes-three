## Decisions (where PLAN is silent)
- D1 Hidden loop = state reconciler over (visibility, role), not an event handler: the only way a host/guest that is ALREADY hidden when its role begins (countdown, migration, drop-in) gets the Worker loop. A hidden guest at the start joins as away (AI plays the seat) — the same honest rule as hiding mid-game.
- D2 Slow-join copy after 8 s of VISIBLE waiting (Source/Overwatch show a "waiting for host" state with a way out rather than an endless spinner); it names the real exit (Esc -> Leave Session). No automatic kick: a host on a slow machine may still be loading.
- D3 Protocol v3 keeps the SNAP header layout (critic wire taps read tick/seq/baseline at bytes 2/6/10) and the §3.7 JSON tree-diff format: every byte saving decodes back to exactly the same JSON op, so the tree-diff law, the hash and replica semantics are unchanged. Only two VIEW changes, both presentation-only on a guest and bounded: mover velocity at 1/65536 u/tick (the host re-anchors against it, view within 1/64 u of truth) and rest unit directions on the 256-step YAW table.
- D4 EVENTS_U resends the PREVIOUS batch only (2 copies of every event, the second 50 ms later — inside the >= 100 ms interpolation delay, and it outlives a short burst that takes two copies sent together). Measured delivery stayed exactly-once (replayedOnce true) with 0 late-event failures in every run.
- D5 Paced fulls instead of a hard per-link token bucket (Q3 `rate`): a bucket would skip snapshots, which the guest's own loss meter would report as packet loss; pacing only the FULLS keeps the seq stream whole and the chip honest.
- D6 In-game roster pings every 10 s (lobby 2 s): the in-game chip reads the guest's own pong; the roster number is informational.
- D7 Budget scope: the §3.7 budget is held in every level and the boss, at N1-N3, with 1 and 3 guests (the critic's reading, agreed by both refuters).
