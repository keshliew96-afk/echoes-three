## Decisions (PLAN silent -> best-in-class choice, recorded here)
- Tool prefix `gntM4a-` (task text; M1/M3/M4b use `gntM1-`/`gntM3-`/`gntM4b-`). The PLAN's named act runner path `tools/gnt-M4a-actrun.mjs` is ALSO provided (critics look it up by that name).
- Pale Lance "pierce 3" = the lance resolves a full instance on up to 3 DIFFERENT bodies along its line (in flight order) and is spent on the 3rd; the sweep continues from each contact inside the tick, so a pierce never slows the lance.
- Damage novas / zones / Detonate bursts reach breakable world objects (neutral `lifecycle: 'break'`: barricades, kegs) as circles of radius max(hx, hz) (PLAN §3.6 (g)); heal shapes stay party-only.
- Statuses: module functions stay pure (M4b calls them from its systems); every record carries `fresh` until announced, and a stateless tracker at the end of each tick (run.js endOfTick) emits `status_apply` / `status_expire` — so every application is announced exactly once, whoever applied it. Stun immunity = an internal `stunImmune` record, live DURING the stun too (a second stun never extends the first). Party stun/exposed and hostile haste/shield/ward/inspired are refused by rule.
- Bulwark: damage side ACCUMULATES on the caster up to 30 (240-tick lifetime, Kindred Shield's window); passive side accumulates +2/pulse up to 10; heal side (overheal) follows the §23.8 refresh rule (max) with the 50%-of-power cap. Every shield is also bounded by 50% max HP.
- Pulse-refreshed statuses (Quiet Hearth ward, passive Snare/Galvanize) last 72 ticks (one cadence + 12), same as Rootsnare's authored slow refresh.
- Resonance counts casts only while it is socketed; the Echo of a resonant cast uses the plain resolved power (Echo recasts never advance or consume Resonance). Its passive cell is the legendary cap (unsocketable) — verdict 'live' with reason legendary_cap so the display never shows a grey strike for a cap block.
- Keen = stat key `critBonus` (+0.15 additive_flat; base 0 on every skill) passed into the ONE crit roll (`roll < 0.05 + bonus`) of every instance the skill produces (primary, echo, bounce, detonate, split).
- Linger = virtual stat `duration`: zones' durationSec ×1.5 (then rounded to whole 1.0 s zone ticks: 4→6, 5→8), a skill's status ticks ×1.5 (stun still capped 60). Grey on passives (their status is pulse-refreshed).
- Widen on arcs scales the half-angle only, clamped at 90°; Widen is grey on area-0 (single-target) projectiles.
- Multiply saturation-inert applies only to PARTY-targeted shapes (heal direct/nova/arc); Bell Toll (damage nova) 5→6 is live.
- Difficulty dmgMul is applied by M4b's spawnScaled (it multiplies its own damage by e.dmgMul); combat.applyDamage never re-applies it (no double scaling).
- The shop room keeps the previous combat room's layout id (biome continuity; M4b spawns no placements in shop/boss rooms). The boss room uses the act's bossLayout.
- Boss per act: minimal hook in boss.js (M4b's file) — `start(x, z, { hp, dmgMul, adds, addHpMul, addDmgMul })`; adds spawn through spawnScaled at room 6's ramp (the ARCH difficulty comment "rooms 7 and 8 reuse room 6's ramp").
- Wave fill: first unit always joins; each draw = weighted type, then an elite roll only when the room's chance > 0, then a spawn point; stop when a drawn unit costs more than remaining + 0.5, or at 8. A due spawn waits in its telegraph while 20 hostiles are alive (run rooms only).
- Autopilot (sim/autopilot.js) is created by run.js and wraps `world.step` in main.js M4a WORLD-LAYERS (so both the realtime loop and `__echoes.sim.stepN` use it); off = pass-through.
- Expedition picker = an app screen (`expedition`) the camp portal pushes only in title sessions with ≥ 2 unlocked acts; E is the menu's tabNext key, so the picker maps keyboard tabNext to "confirm". Unlocks: profile (M2) + acts won this session + a probe override `__echoes.content.unlock([1,2])`.
- Challenge row: `gameplay.challenge` registered by M4a (ui/run/challenge.js) into M1's Gameplay tab; read at the portal press / `?run=1` autostart.
- Esc: path/shop/end pages no longer consume Escape (the end card's Esc-to-camp removed); draft decline = X (a commit key: settle-guarded + fresh-press) or the button; socket Esc calls preventDefault.
- HUD: shield on the portrait = a Parchment hex rim + a points plate (24 virtual px -> ≥ 16.5 real px at the clamp); burrowed threats get a dashed Bone "dirt-ripple" pointer variant.
