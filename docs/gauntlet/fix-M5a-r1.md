- [x] Step 2: FIX (committed as v0.5.72). Design (PLAN §3.7 is silent on how loss is measured/shown; best-in-class = Source net_graph incoming loss + Overwatch/Valorant in/out loss and connection icons):
  - DOWNSTREAM (guest): src/net/transport.js `SeqLossMeter` — distinct snapshot seqs vs the seq span over a 5 s window (entries kept 1 s longer so a reordered seq still counts), duplicates/reordering harmless, a seq restart (migration) or a jump > 200 (stall/reconnect) starts a fresh window; null until 20 seqs are spanned. src/net/lobbyClient.js peeks every SNAP header in onBinary BEFORE the session driver takes the frame (so it works for the M5b driver and the W3 probe stream alike) and resets on reconnect, host change and on leaving the session.
  - UPSTREAM (guest): the host already measured each guest's input-packet gaps (driver feeds); src/net/driver.js (M5b's file, minimal edit) now computes it per seat over 5 s (`feedLossPct`, cached 500 ms) and passes it to `snap.encodeFor({ upLossPct })`; src/net/protocol/snapshot.js carries it in the snapshot header flags bits 0-6 (0 = not measured, else 1 + whole %). Bits 0-6 were unused (callers never passed flags) and old decoders ignore them, so the header size, the delta ratio and PROTOCOL_VERSION are unchanged (unit: same 65-byte frame with and without the echo). Host stats gain `lossBySeat`.
  - stats(): `lossPct` (guest = the worse direction; host = the driver's aggregate, unchanged), `lossInPct`, `lossOutPct`, `lossInWindow {pct,got,expected}`, `snapshotAgeMs`, `quality { level good|fair|poor, reasons [stalled|loss|latency|jitter], raw, sinceMs, lossPct }`. Hysteresis: worse shows at once, better only after holding 2 s. A HOST's chip judges its OWN link = the loss every guest's inputs share (min of lossBySeat), so one guest's bad link shows on that guest's chip, and on the host as a note naming the seat.
  - HUD (src/ui/net/hud.js, M5b's file cited by the failure): the chip's link part = 3 signal bars (good 3 Parchment / fair 2 Hearth Amber / poor 1 Hearth Amber + "!" badge + amber border), ping, and "N% loss" whenever >= 1 %; "no updates" when stalled; title/aria-label spell out in/out loss.
