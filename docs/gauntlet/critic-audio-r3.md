## Step 1 — Blind benchmark checklist (written BEFORE inspecting any Echoes capture)

Reference systems: FMOD Studio / Wwise bus mixing as shipped in Hades (FMOD) and Dead Cells; the dB-perceptual volume convention of shipped PC games; HTML5/Web Audio games that handle browser autoplay policy correctly.

| ID | Benchmark behaviour (testable) | Source system |
|---|---|---|
| B1 | Bus hierarchy: Music and SFX buses are children of Master; effective gain = master x channel (multiplicative), each slider touches only its own bus | FMOD/Wwise buses (Hades: Master/Music/SFX/Voice) |
| B2 | Decoupling: moving Music changes SFX bus level by 0 dB (and vice versa); measured, not claimed | FMOD VCA per bus |
| B3 | Slider at 0 is true silence (gain 0 / -inf dB, no residual hiss or -40 dB floor) | all shipped PC games |
| B4 | Perceptual taper: a "log"/perceptual slider maps position to dB (typically -60..0 dB or amp=x^2..x^3) so 50 % sounds about half as loud (about -10 dB to -20 dB); linear mode gain == slider fraction | dB-perceptual convention |
| B5 | No zipper noise: gain changes are ramped (10-50 ms smoothing) | FMOD parameter seek speed / Web Audio setTargetAtTime |
| B6 | Music in every state (menu, hub, combat, boss) with crossfades on transitions, no dead air > 1 s | Hades room/boss music transitions, Dead Cells biome crossfades |
| B7 | Pause/menus attenuate or low-pass the music instead of hard cutting it; gameplay SFX voices pause | Hades pause low-pass snapshot |
| B8 | End-of-chain limiter/compressor; voice limiting per event (max N instances, steal oldest); no sample above 0 dBFS in a dense boss fight | FMOD max instances + master limiter |
| B9 | Spatial SFX: stereo pan by world x relative to listener, distance attenuation; left event is louder in L channel | FMOD 3D events in top-down games |
| B10 | Repetition control: pitch/volume randomisation on repeated hits | Dead Cells/Hades hit SFX |
| B11 | UI sounds (move/confirm/back) exist and obey the SFX (or UI) slider | shipped PC menus |
| B12 | Settings persist across reload and are applied at boot before the first sound | shipped PC games |
| B13 | Master mute toggle independent of slider value; unmute restores the previous level | PC games / Web games |
| B14 | Background/unfocused behaviour: mute-or-duck when the tab/window loses focus (option), honest if not | Dead Cells "mute when unfocused" |
| B15 | Autoplay: AudioContext created/resumed on the first user gesture; no console autoplay errors; music starts on first gesture; blocked state handled gracefully | HTML5 games |
| B16 | Slider preview: moving the SFX slider plays a sample blip so the level is audible | Hades / many PC games |
| B17 | Numeric readout per slider; keyboard arrows/Home/End adjust, mouse drag/click, gamepad left/right | PC UX standard |
| B18 | Balance: SFX transient peaks sit above the music bed by a sane margin (about 6-12 dB), nothing drowned, defaults below 100 % leave headroom | shipped mixes |
| B19 | Reset-to-defaults for the audio tab | PC settings UX |
| B20 | Survives suspend/resume and HMR without stuck or doubled voices | Web Audio games |
| B21 | Scene/level transitions stop per-level voices (no leaking loops into the next level/lobby) | FMOD bank unload / Stop-all on scene change |
