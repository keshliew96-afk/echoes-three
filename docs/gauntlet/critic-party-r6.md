(AtO: "skip" card reward / remove; D3: swapping skills in a slot; DD: swap at camp.) | AtO, D3, DD | With 4 owned the reward stays a SKILL card offering "replace X" for each of the 4 + "keep current"; replaced skill returns to pool; nothing silently lost. |
| B4 | Ownership is always labelled: every reward/shop card shows the hero portrait/name/colour it is for (AtO shows the hero portrait on each reward screen and the deck owner on every card list). | AtO, CoM | Each card and socket shows character name/icon; a screenshot alone tells you whose it is. |
| B5 | Switching which hero you're viewing is 1 input (AtO: click hero portrait / Q-E; DD: click hero; CoM: character select). | AtO, DD | Switch character in <= 2 inputs on keyboard, mouse, gamepad (LB/RB). |

| B8 | Builds persist across the run's stages (AtO across acts; CoM across a dungeon run; Hades across chambers) and survive save/quit/continue. | AtO, Hades, CoM | All 4 builds carry level->level, survive save/load + migration. |
