## Decisions
- D1 Repair, don't refuse, when the drift is removable: a save whose only problem is content this build lacks loads with that content removed and a toast naming it (the shipped-game norm for removed content — the save keeps working, the player is told). Refusing would strand every save made before a content update. The file itself is never rewritten (a build that has the content still loads it whole); the repair applies to the load's private clone.
- D2 Never lose the player's nodes: a skill that leaves the loadout releases its socketed nodes to that character's bench with provenance (BUILD_BRIEF ruling A17, the same rule as a swap and MIGRATIONS[1]); only node ids the build does not know are dropped.
- D3 Strict no-op on valid trees (proved on 12 moments headless + G2.1 round trips + goldens): every rule acts only on an unknown / impossible id, nothing is re-ordered or re-created otherwise, so no save of this build changes hash.
- D4 Defence in depth: after the reconcile, io.apply runs the live read paths once (world.snapshotState: run view, skill slots, build view; party view) and rolls back a tree that still throws — new error code 'content' ("That save needs content this version of Echoes doesn't have — it can't be loaded here"), layers resync with state_restored { reason: 'rollback' }. A dry-run sim step was rejected: the bus has no presentation mute, so a step would leak one tick of sounds / VFX to the player; the read check catches the per-frame failure class the critic hit (proved with reconcile off: refused, exact rollback).
