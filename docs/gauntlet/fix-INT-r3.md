## Decisions (where PLAN is silent)
- D1 (J3-F2) The boot splash is static HTML that mirrors the loading screen rule for rule (same wordmark, rule, bar, status, hidden press box, --ap-s) so the hand-over to the JS loading screen is a pixel-identical cut (measured 0 px deltas) — Hades / Dead Cells show their logo + loader at once and never the raw game before it. The bar is a transform-only sweep (compositor thread) because the main thread is busy for seconds during parse / world build; prefers-reduced-motion gets a breathing bar.
- D2 (J3-F2) One-frame yield at the top of main.js (top-level await, cap 1.5 s, no wait in hidden tabs): on a cold browser the module body used to start before the compositor had drawn anything. Cost: one frame; side effect: DOMContentLoaded / load fire before window.__echoes exists (documented in TESTING.md; openEchoes / cert-capture unaffected — every critic tool reviewed polls).
- D3 (J3-F2) Honest failure: an error / failed script that leaves the splash unclaimed 4 s later becomes "Echoes couldn't start." + reason + focused Reload (network: "check the connection"); > 15 s says it is still loading. A stray error followed by a normal hand-over shows nothing.
- D4 (J3-F3) Two layers, not one: (a) autosaves rotate PER GAME (Skyrim / Fallout keep autosaves per character) so a Save & Quit run survives a new game and a loaded game without any dialog; (b) the title's New Game over a run in progress asks (Slay the Spire "Abandon run?", Dead Cells) and says truthfully what happens: kept (default Start New Game — nothing is lost) or, only when both autosave slots already hold other games' runs, "Replace a saved run?" naming the older run (danger, default Keep My Run). app.newGame() (API / harness path, MP host start) stays confirm-free.
- D5 (J3-F3) Game key = the run seed (constant through a campaign's levels — no reseed at a transition — new per campaign). Games that ended (victory, defeat, Quit to Lobby) are remembered in echoes.save.v1.endedRuns (last 24) so their leftover autosave is an ordinary old save (rotated, not announced); loading one revives it.
- D6 (J3-F3) No confirm on the title's Load Game: the loaded game's autosaves already spare the suspended run (leg `load`). With three or more concurrent games the older run can still be replaced — only ever after the New Game dialog named it (two autosave slots are the PLAN's §3.4 budget).
- D7 (J3-F1) No code change by INT: the root cause was fixed by M2 (fix-M2-r3 F2, 390b602); INT re-verified it on the exact real player path on dev + production.
