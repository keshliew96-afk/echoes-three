Advisory A (not blocking): **downed tiles lose WHO is down.** With the Tank and
the Archer both down (`xhd-states-d-bar2x.png`) the two tiles read as the same
object — a Bone ring with an `E`. Measured: F2 vs F4 tile mean abs diff
14.4/channel (healthy F2 vs F4 in `xhd-cd.png`: 45.0), the only class signal
is the 2 px hairline whose lifts differ by <=11/255 (`rgb(182,175,166)` vs
`rgb(184,186,155)`), the F-key chip is hidden and the bust is rotated 78°,
clipped 24 % top/bottom, `grayscale(0.88)` and scaled 0.8 into a smear. Fix
direction: keep the F-key chip (or a class letter) on the downed tile and use
the class BASE accent (`#6B6157` vs `#6E7A3F`, much further apart) for the
hairline and track rim; ease the grayscale so the bust silhouette survives.

Advisory B: the §17 **2x reverse drain is unobservable** whenever an AI
reviver is adjacent — the sim replaces the draining channel with a fresh one on
the same tick (`reviveState` after the break: a new channel at `progress 7`,
`draining false`), so only the shake reads. Sim behaviour, not HUD; noted for
the allies block.

- Banner kill_all: `WAVE 1/3  ●○○  8 LEFT` (pips: done Parchment / current

  `THE HOLLOW STAG [violet bar] 100/200` with a God-stuff Violet rim, 788x35.

reward card (or defer that construction one frame), or drop the CSS
transition from 170 ms to ~120 ms so the budget survives the stall.
