## Advisories (not blocking)

- **A1 Fresh-camp gate reopen (debug-only regression).** Before any run has
  started, a stray `cmd('startRoom','kill_all')` in the default CAMP scene opens
  the gate: `zhd-camp-leak0` (spawn succeeds, `ids [4,5]`) shows `hud.combat()
  combat:true`, banner **"WAVE 1/3 · 7 LEFT"** and pointers painted **over the
  campfire** — banner box (644,14,312,35) ink 906, luma>200 866; pointer
  (1554,585) ink 119. This is a regression vs v0.4.14, where `readCombat`
  required `runSystem.isActive()` (false in camp, so the gate stayed shut). Root:
  the new `readCombat` mirrors `run.js combatAllowed()`, whose `!everStarted`
  branch is scene-agnostic, so it also lights a live room in the fresh camp
  scene. **Not player- or harness-reachable** — nothing but the debug `startRoom`
  cmd creates an uncleared room in camp (the portal press calls `startRun`, which
  swaps to the arena scene), and the sanctioned post-run leak2 case stays shut
  via `everStarted`. Because item 2 (the `?room=` arena boot) *requires* the
  `!everStarted` branch, the fix is to scope it to the arena: in `readCombat`,
  only allow the pre-run branch when `snap.scene !== 'camp'` (or when the room
  came from the `?room=` param) — leaving the harness boot lit while the camp
  gate stays shut even against a stray `startRoom`. Re-verify with
  `zhd-camp-leak0` (must gate) and `zhd-smoke-arena` (must stay lit).

- **A2 "N ADDS REMAIN" is dead text.** The felled plate always reads
  "CLEAR THE ADDS", never "3 ADDS REMAIN", so the player never sees the add
  count tick down during the mop-up. `banner.js` computes `adds = boss.adds ??
  …`, but the HUD's `runBoss` (built in `pollRoom`, `index.js`) forwards only
  `{name, hp, maxHp}` and drops the count, so `boss.adds` is always undefined and
  the "N ADDS REMAIN" branch can never fire. The task lists the two strings as
  alternatives ("/") and the dead-boss "0/1800" is gone, so this is not a block —
  but forwarding `b.adds` into `runBoss` would light the live count.

- **A3 "0.0" numeral.** `zhd-cd2` frame i=10 shows slot 1 "0.0" for the last
  1–2 ticks before the numeral clears. Floor the display at "0.1" or hide the
  numeral once remaining < 3 ticks. Cosmetic; carried over from D2 A5.
